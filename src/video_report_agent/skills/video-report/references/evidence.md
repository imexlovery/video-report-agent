# Evidence：方法、证据与结论

主线是结果如何获得、证据支持什么结论；出现数字或研究引用不决定 Profile。取舍与展开服从所选模式。

- 连接问题、方法、样本或测试条件、结果及结论，区分实测、转述与解释；决定性限制紧邻结果。
- 比较保留对象、指标、单位、基准及可比条件，不同口径分开；单次、局部或特定配置的结果不泛化。
- 证据链可表达支持关系，表格用于跨对象或指标对照，机制图不能代替实证。方法或限制缺失时保留实际缺口，不补研究设计或虚构缺陷。

例如新闻主题、次数与多条事件需要对照时，表内保留比较字段和简短代表条目，长事件按主题在表后展开；短事件可用单元格内列表。列宽、样式与详略服从模式，日期和统计口径不因腾空间丢失。
