# Argument：议题、立场与依据

主线是判断、立场及其依据；单人可适用，多人对话也可能采用其他主线。取舍与展开服从所选模式。

- 按议题聚拢人物的判断、理由、例子和回应，不按发言顺序抄录；区分事实、价值判断、经历、预测与建议。
- 说明来源支持的前提、证据、目标或价值分歧，只有材料支持时才归纳共识；提问不是主张，未回应不是赞同，二手转述不是原话。
- 多人对同一议题表态时可用立场与依据矩阵；单人论证保留“判断—依据—限定”的衔接，不虚设对方或对等证据。观点变化保留语境。

短发言只有一个预测、两个理由和一个失效条件时，同一单元直接讲清归属、依据与条件，不再叠摘要、地图、四章正文和重复结尾。未来路径遵守共用预测标识。
