# Mechanism：机制与关系

主线是解释对象如何相互作用、结果如何产生及成立条件；术语或公式的出现不决定 Profile。取舍与展开服从所选模式。

- 在首次需要处定义对象，依理解依赖组织作用路径、结果与条件；来源有输入、状态、输出或反馈时才展开这些关系。
- 保留改变机制成立范围的条件和反例，推导与例子按模式选择。来源缺失的对象、公式项或回路不凭领域知识补齐。
- 位置、方向、状态或资源流转是核心时用关系图或前后对照；公式与段落承担必要推导。箭头标清动作及流转内容，不以抽象标签链代替解释。

例如来源只有“窗口内上下文通过工具检索外部事实，结果返回用于回答”，可画两个区域、检索与返回箭头，再连接回答；不补写入、删除或失败分支。邻近正文补来源给出的用途与限制，不复述图。
