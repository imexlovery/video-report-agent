# 标准阅读（standard）

仅 `standard` 读取本文件和 [Standard 模板](../assets/report-template.html)，使用其组件、样式与示例。内容自适应详略，短来源不为区分 Brief 而加长；不读取另一模式或混入 `brief-` 资源。

## 篇幅与阅读深度

以读者完整理解主要问题所需的最小充分展开为目标，不以篇幅、细节数量或长图高度证明质量。默认直接进入有效内容，不预设“摘要—地图—正文”；按用户用途、独立问题、关系复杂度与必要依据决定详略，用户明确的深度优先，只生成当前一份报告。

| 来源提示 | 编辑起点 |
|---|---|
| 约 10 分钟以内、单一问题 | 核心判断、现有对照或步骤组件直接承担内容，条件与依据就地补充，一个模块已讲清即可结束 |
| 约 10–30 分钟、相关问题较多 | 按问题组织模块，保留代表性依据与例子 |
| 约 30 分钟以上、密集或复杂依赖 | 展开理解所需的方法、推导、条件与例子，需要定位时加章节导航 |

时长只作提示，不换算字数、章数或组件数，无可靠时长不编造。密集短推导可以精读，重复长闲聊可以压缩。必要的推导、步骤、条件与代表依据保留；重复背景、同作用例子及不影响理解的口述细节可删，不逐项复刻来源。内容已讲清就结束，不为覆盖全部素材继续加章。深度与读者基础分别判断：未指定受众时就地解释关键术语，不假定儿童或专家；类比须接回真实关系，展开仅在来源范围内，不同展开程度保留同样的事实、结论强度和决定性条件。

## 正文组织与阅读节奏

按理解依赖组织核心概念、关系、依据和代表性例子；每个单元有明确重心，例子与反例靠近论点。回答同一问题的内容合并，只有新增理解任务或必要依赖时另立大章。章内需要阅读停靠的主题转换再用具体小标题，短项用列表，不为每个例子、术语或时间点起标题。同层内容只有新增条件、证据或应用时才再次展开。

并列、比较、操作与关系优先结构化，叙事、论证和推导可用连贯段落。**不连续堆积三段及以上的大段文字**；以实际版面中密集、需逐行阅读的负担判断，不设机械字数阈值。多段短文或单段混入多种关系同样应按重心重组，不靠空标题、底色、加粗或整片装卡片打断计数，也不机械改成 bullet。

多个大章节从 1 连续编号；单一或紧凑模块报告可省略大章编号，概览与导航不占章号。沿用模板浅灰画布、纯白纸面和约 16–17px 正文，强调色用于局部；仅复用模板现有组件，遵守入口的禁止自绘规则。

## 用形式表达关系

先识别每个内容块的关系、必要字段与阅读任务，再选择表达；正文可以是最佳选择。下表与模板中的结构示例共同使用。没有来源支持的数值、分母、作用方向或条件时，不为组件补造数据。`.cards` 与 `.comparison` 共用双栏外观；`.categories-stacked` 是分类卡的布局变体，不靠切换名字制造多样性。

| 关系与表达 | 必需字段、正确用例 | 不适合的用法与降级 |
|---|---|---|
| 普通叙述、短判断 → p / 原生列表 | 对象、判断及必要条件；一句结论直接写正文 | 不把一句话扩成卡片；推导保留连续段落 |
| 名称与解释 → dl.definitions | dt 名称、dd 解释；三个术语各有独立解释 | 需要跨项逐字段比较时改表格；长解释改小节，缺少名称用正文 |
| 少量数值 → stats / 紧凑表格 | 对象、数值、单位、口径；同商品两渠道价格并排 | 不同条件的数字不暗示可比；保留“最高”、分母与时间，条件长则列表 |
| 量级差距 → bars | 同指标、同尺度与单位；同条件三组计数 | 不可比口径分开；数值缺失用文字，不以条长表示未知量 |
| 输入、处理、输出 → mapping | 每行三者俱全；测量值→单位换算→统一单位结果 | 独立任务各占一行，不连成流水线；缺字段用定义列表，说明长用表格或步骤 |
| 短阶段路线 → steps.steps-route | 有来源的顺序、阶段名、必要条件；采样→测量→分析 | 阶段解释长、数量多造成拥挤时退回 steps；无顺序用列表 |
| 展开的操作、证据链 → steps / ol | 动作或证据、依赖条件；问题—方法—结果 | 不补缺失环节；简短事项用普通 ol，不逐项高卡片化 |
| 条件路径、候选解释、定性取舍 → branches | 共同问题及各支条件、动作或解释；失败的两种待验证解释 | 标明“可能”“待检验”与关系性质；连接线不表示概率，复杂多层用嵌套列表或独立图示 |
| 多对象共享多个维度 → table | 明确行列维度与口径；多个方案对照成本、时间 | 只剩名称加长解释时用 definitions / evidence-rows；缺少字段且不影响判断则不建该列 |
| 少量定性对照 → comparison / cards | 相同问题、可对应的区别；同对象前后状态 | 长短悬殊、无比较收益时用开放式条目；只有一个对象用正文 |
| 并列分类 → categories | 类别名、特点；短分类并排 | 长短悬殊用 categories-stacked；每类需精读用 categories-detailed；不拆有依赖的步骤 |
| 独立判断与长依据 → evidence-rows | 事项、判断、依据；逐项解释测试偏差 | 不重复“正确”等状态填版式；共同比较字段用表格，短项用列表 |
| 研究证据摘要 → definitions，可邻接 stats | 来源实际给出的样本、结果、观察条件、范围；计数带分母，结论紧邻条件 | 不同研究结果不脱离条件并排；缺失关键条件明确保留未知，其他未给字段省略，不补研究设计 |
| 公式、定义、带条件结论 → callout；独立短归纳 → keyline / tiles | 有独立阅读价值的公式或综合结论 | 普通判断用正文加粗；不重复图表已有数字、步骤与分类，也不把长论证塞进色块 |
| 复杂空间、机制关系 → 现有 generate_diagram | 来源支持的对象、关系、边界，说明需图示解决的问题 | 简单映射、步骤优先现有组件；工具未提供时用文字，不自造关系；四节点闭环仅匹配时复用 cycle-map |

图表承担已展示的数字、步骤与分类，邻近正文只补解释、结论和决定性条件。不得删除单位、分母、适用范围、时间或 data-source-*；从表格移到条目时，按实际支撑内容迁移来源绑定。

### 整篇表达检查

在入口既有的一轮集中检查中，浏览相邻重型组件、连续大色块、蓝表格各自的行列含义、卡片长段落和图文复述。先判断信息结构是否相同、能否降低阅读负担，再调整：独立长解释移出表格，短判断回到正文，图中已完整表达的枚举不在正文复读。相同结构重复使用同一组件有利于比较，应保留；不设置种类或次数配额，不随机换色。不增加模型轮次或另设布局 Agent。

### 分类详解与依据行

`.categories.categories-detailed` 适用于真正并列、需要精读的类型，不强拆叙事或有依赖的步骤。每个 `.category` 单列自然高度，`h3` 标类型，代表对象或范围按需用 `.category-meta`，多个对象或案例用 `h4`；类内并列用列表，机制与推导用段落，不再嵌套卡片。总览表只有跨类型对照有用时保留，详解补新增依据，导航可直接链接类型标题。

保留模板白底、细彩色左边线与留白；`data-tone` 可区分类型，同类颜色一致、不暗示排名或风险，不改成标题色块。`.category-number` 可作定位。解释框与归纳框保留纯浅色填充，不沿用分类卡的边线。

`.evidence-rows` 用于逐项理解独立判断与长依据；需要反复对齐同一字段时仍用表格。不要为填版式重复“属实”“正确”等状态，实际状态差异在正文说明；编号仅定位，行间沿用留白，不加长横线或编号旁小点。短项用列表。

### 表格列宽与长说明

沿用模板自动列宽、浅蓝表头、白底正文行和细分隔，不默认等宽 `colgroup` 或 `table-layout:fixed`。短标签、数值表可用 `.table-compact`；长说明表用 `.table-details`，语义行标题写为 `th scope="row"`，使模板的最小宽度保护短标签。拥挤时再依实际内容调整，不全局禁换行或缩字号；数值列 `.table-number`。

单元格用短关键词与普通说明分层，多条件用条目。长解释挤窄标签或使其他列大片空白时移到对应小节，表内只留比较内容；保留日期、口径及条件，不与正文重复。来源未展开的对象不为凑表格逐列填“未说明”，仅在缺失影响比较时标明。

### 现有图形组件

遵守入口的组件范围。模板四节点循环组件只有在来源恰有四个节点及闭合反馈时可直接复用；替换文字与来源、唯一化组件 ID 及引用，保留现有结构、坐标、路径、标记形状和样式。文字放不下或关系不适配时改用步骤、表格或列表，不重排几何，也不补造回路。

### 数量图

数字通常用正文、紧凑列表、表格或 `.stats`；只有量级、比例或差距是核心，且柱长明显降低比较成本时才画柱图。零散数字、一前一后两个值、价格档位或单个百分比不默认画图，不反复以柱图收尾。

选用柱图时复用 `.bars/bar` 组件，不自写填充 CSS；同组从零起、共用刻度、柱长对应数值，同序列同色，重点可用 `.bar-highlight`。深色标签与数值放色条外，量纲不同分组；仅相对变化可设标明的基准指数 100，变化箭头按需。不可比数据不合并，重复图删除。

### 长文的桌面章节导航

长文有定位收益时在 `{{BODY}}` 开头使用模板 `.report-nav`，标题“目录”，短标签链接真实章节 `id`，与正文同序，序号由模板生成。沿用左侧页外书签、滚动高亮和平滑跳转，不加摘要、阅读状态、进度条或另画导航样式。窄屏、打印和 920px 长图由模板隐藏，不塞回题头或另做无导航 HTML。

## 章节时间与修订

有可靠时间的大章节在标题右侧用 `.section-time`，每章最多显示一个时间区间，用原生 `<a>` 链接到原视频的区间起点；Bilibili 用 `t=起点秒数`，YouTube 用 `t=起点秒数s`。保留原视频与分集参数，替换已有定位参数，HTML 查询参数用 `&amp;` 连接；无可定位的原视频链接时保留纯时间文本。时间固定在 `h2` 右侧且不换行，长标题在左侧自然换行；沿用模板的 12px、常规字重与 `#666666`，链接保留下划线，无底色、边框或前缀。正文、组件与目录不重复定位时间，用户明确要求逐条定位时除外。

时间统一补零 `MM:SS–MM:SS`，来源达到一小时则全文用 `HH:MM:SS–HH:MM:SS`；起点向下、终点向上取整至秒。按重组后实际使用来源的最早起点与最晚终点标记章节定位范围；即使对应多个不连续片段，也只显示这一个区间，不并列多个时间或追加“等 N 处”。完整来源继续保留在隐藏绑定中；无可靠时间省略，不凭篇幅推算或虚构总结时间。

把标题重复、最密集单元、最窄表格列、顶部是否及时进入内容及章节时间，全部纳入入口的唯一一轮集中检查；实际问题只做一次集中修订。不能少写决定性条件、缩字号或隐藏正文；复核仅限修改影响处，不另开模式专项检查。静态、数值和实际渲染检查分别如实报告。
