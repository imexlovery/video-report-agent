# 标准阅读（standard）

仅 `standard` 读取本文件和 [Standard 模板](../assets/report-template.html)，使用其组件、样式与示例。内容自适应详略，短来源不为区分 Brief 而加长；不读取另一模式或混入 `brief-` 资源。

## 篇幅与阅读深度

以读者完整理解主要问题所需的最小充分展开为目标，不以篇幅、细节数量或长图高度证明质量。默认直接进入有效内容，不预设“摘要—地图—正文”；按用户用途、独立问题、关系复杂度与必要依据决定详略，用户明确的深度优先，只生成当前一份报告。

| 来源提示 | 编辑起点 |
|---|---|
| 约 10 分钟以内、单一问题 | 核心判断、对照、步骤或主图直接承担内容，条件与依据就地补充，一个模块已讲清即可结束 |
| 约 10–30 分钟、相关问题较多 | 按问题组织模块，保留代表性依据与例子 |
| 约 30 分钟以上、密集或复杂依赖 | 展开理解所需的方法、推导、条件与例子，需要定位时加章节导航 |

时长只作提示，不换算字数、章数或组件数，无可靠时长不编造。密集短推导可以精读，重复长闲聊可以压缩。必要的推导、步骤、条件与代表依据保留；重复背景、同作用例子及不影响理解的口述细节可删，不逐项复刻来源。内容已讲清就结束，不为覆盖全部素材继续加章。深度与读者基础分别判断：未指定受众时就地解释关键术语，不假定儿童或专家；类比须接回真实关系，展开仅在来源范围内，不同展开程度保留同样的事实、结论强度和决定性条件。

## 正文组织与阅读节奏

按理解依赖组织核心概念、关系、依据和代表性例子；每个单元有明确重心，例子与反例靠近论点。回答同一问题的内容合并，只有新增理解任务或必要依赖时另立大章。章内需要阅读停靠的主题转换再用具体小标题，短项用列表，不为每个例子、术语或时间点起标题。同层内容只有新增条件、证据或应用时才再次展开。

并列、比较、操作与关系优先结构化，叙事、论证和推导可用连贯段落。**不连续堆积三段及以上的大段文字**；以实际版面中密集、需逐行阅读的负担判断，不设机械字数阈值。多段短文或单段混入多种关系同样应按重心重组，不靠空标题、底色、加粗或整片装卡片打断计数，也不机械改成 bullet。

多个大章节从 1 连续编号；单一或紧凑模块报告可省略大章编号，概览与导航不占章号。沿用模板浅灰画布、纯白纸面和约 16–17px 正文，强调色用于局部；内容可自由采用 HTML/CSS 或内联 SVG，视觉分量与信息重要性相称。

## 用形式表达关系

| 阅读任务 | 表达选择 |
|---|---|
| 并列定义、特点或建议 | 原生列表，句首关键词加粗，解释普通字重 |
| 简短有序项目 | 原生有序列表，名称与短说明同项呈现，不逐项扩成高卡片 |
| 有展开价值的操作、阶段或路径 | `.steps`、流程或关系图；条件选择用分支树 |
| 空间、作用方向、层次或状态是核心 | 对象标清的剖面、关系图或前后对照，文字补依据与条件，不仅用文字卡片描述图景 |
| 多对象或时点共享属性，需要跨项比较 | 多项数值/字段用表格对齐；少量定性区别用 `.comparison`、`.cards` 或普通 `.categories` |
| 每个并列类型都有较长独立解释 | 单列 `.categories.categories-detailed > .category` |
| 少量事项各有长依据，主要逐项理解 | `.evidence-rows`：左侧事项，右侧判断与依据 |
| 公式、定义、重要区别、带条件结论 | `.callout`；独立短归纳可用 `.keyline`、`.tiles` |
| 事件与转折、问题到证据的支持路径 | 时间轴或证据链，材料缺口保留，不补完整链条 |

上述是选用指引，模板不是封闭组件库，也不要求全部出现。卡片按实际数量均衡布局；并列类别长短悬殊、主要逐项阅读而无需逐字段对照时，用 `.categories.categories-stacked` 让卡片单列自然高度顺序呈现，保留原文限定。需要横向比较时仍用并排卡或表格；仅有名称、数值或一句说明时用紧凑列表、表格或分栏。

### 分类详解与依据行

`.categories.categories-detailed` 适用于真正并列、需要精读的类型，不强拆叙事或有依赖的步骤。每个 `.category` 单列自然高度，`h3` 标类型，代表对象或范围按需用 `.category-meta`，多个对象或案例用 `h4`；类内并列用列表，机制与推导用段落，不再嵌套卡片。总览表只有跨类型对照有用时保留，详解补新增依据，导航可直接链接类型标题。

保留模板白底、细彩色左边线与留白；`data-tone` 可区分类型，同类颜色一致、不暗示排名或风险，不改成标题色块。`.category-number` 可作定位。解释框与归纳框保留纯浅色填充，不沿用分类卡的边线。

`.evidence-rows` 用于逐项理解独立判断与长依据；需要反复对齐同一字段时仍用表格。不要为填版式重复“属实”“正确”等状态，实际状态差异在正文说明；编号仅定位，行间沿用留白，不加长横线或编号旁小点。短项用列表。

### 表格列宽与长说明

沿用模板自动列宽、浅蓝表头、白底正文行和细分隔，不默认等宽 `colgroup` 或 `table-layout:fixed`。短标签、数值表可用 `.table-compact`；长说明表用 `.table-details`，语义行标题写为 `th scope="row"`，使模板的最小宽度保护短标签。拥挤时再依实际内容调整，不全局禁换行或缩字号；数值列 `.table-number`。

单元格用短关键词与普通说明分层，多条件用条目。长解释挤窄标签或使其他列大片空白时移到对应小节，表内只留比较内容；保留日期、口径及条件，不与正文重复。来源未展开的对象不为凑表格逐列填“未说明”，仅在缺失影响比较时标明。

### 图示的选择、绘制与检查

图形能降低理解关系的成本时才画。核心空间或作用路径需要读者脑中拼图、且来源足够时，在首次解释处直接画清对象、方向及条件；纯叙事或公式已清楚时保留文字。关系标签按实际字长避让，间隙不足可放节点上方并对齐对应边。一图一个解释目标，尺寸与关系复杂度相称，少量节点紧凑排布，不用高大卡片或过长连线撑版面；复杂时先减少无助理解的标注，再按需拆图。

精确函数、几何或比例先据来源公式和数据用代码计算，再绘制，共用坐标映射，标明刻度、名称、单位及非线性尺度；核对关键值、交点、方向、比例与正文，平滑曲线不出现拼接折角。概念图也核对连接与边界：共享坐标的图内，同一交点或分界共用位置，不能为留白拆成两个端点或把点画成区间；相接、连续和分离关系与正文一致，不用“不按比例”掩盖错误。

有 Bash 时脚本只写在本次工作区，Pi 可用 `"$VIDEO_REPORT_PYTHON" draw.py`；独立使用选已确认的解释器。简单计算与 SVG 可用标准库，其他库仅在已安装时使用，不安装包。最终图示内联，不依赖本地图片或运行时 Python。

有视觉工具时检查遮挡、裁切与标注，遵守当前检查次数限制，不另开反复修图循环；只有计算或静态检查就如实说明。来源、工具不足或关键错误无法修好时改用能核实的简单图、公式、文字或表格。

### 循环图的布局与连线

只有来源支持闭合反馈才画循环，模板四节点 SVG 仅供几何参考。先安排完整回路再放节点，按实际数量与文字宽度均衡分布，不把横向流程换行后长折返；上下两排时下排沿回路反向阅读。

- 同类节点尺寸与形状一致，保留名称和短说明，长解释放图旁，不叠编号、图标、阴影与粗线。
- 复用 `.cycle-edge` 的细线与开放箭头，直连处用直线，转向才用简单曲线。marker ID 图内唯一，`markerUnits="userSpaceOnUse"`、`orient="auto"`，箭头与边同色同粗。
- 连接点按相邻位置及切线选相向边缘，路径在边界外约 4–8px 止住，尖端朝目标，回程同样核对；不穿过节点、文字或箭头。
- 标签靠近对应边并留间距，`viewBox` 为曲线与 marker 留边距；实际渲染沿回路检查顺序、方向、对齐、重叠和裁切。

### 数量图与强调框

数字通常用正文、紧凑列表、表格或 `.stats`；只有量级、比例或差距是核心，且柱长明显降低比较成本时才画柱图。零散数字、一前一后两个值、价格档位或单个百分比不默认画图，不反复以柱图收尾。

选用柱图时复用 `.bars/bar` 组件，不自写填充 CSS；同组从零起、共用刻度、柱长对应数值，同序列同色，重点可用 `.bar-highlight`。深色标签与数值放色条外，量纲不同分组；仅相对变化可设标明的基准指数 100，变化箭头按需。不可比数据不合并，重复图删除。

强调框只承载准确公式、定义、核实引语、关键区别或带条件结论，保留变量、运算符与必要条件，图框自足，不放泛泛金句或把经验倍数包装成精确换算。

### 长文的桌面章节导航

长文有定位收益时在 `{{BODY}}` 开头使用模板 `.report-nav`，标题“目录”，短标签链接真实章节 `id`，与正文同序，序号由模板生成。沿用左侧页外书签、滚动高亮和平滑跳转，不加摘要、阅读状态、进度条或另画导航样式。窄屏、打印和 920px 长图由模板隐藏，不塞回题头或另做无导航 HTML。

## 章节时间与修订

有可靠时间的大章节在标题区用 `<span class="section-time">02:15–08:40</span>`，优先位于 `h2` 右侧，拥挤时紧邻标题；12px、常规字重、`#666666`，无底色、边框或前缀。正文、组件与目录不重复定位时间，用户明确要求逐条定位时除外。

时间统一补零 `MM:SS–MM:SS`，来源达到一小时则全文用 `HH:MM:SS–HH:MM:SS`；起点向下、终点向上取整至秒。按重组后实际使用来源标记，不连续区间用中文分号分隔；无可靠时间省略，不凭篇幅推算或虚构总结时间。

依入口集中修订，先只读各级标题，合并同义问题、无独立展开价值的小节，删去重复图文和占地过大的简单组件；不能以少写决定性条件、缩字号或隐藏正文换取短图。再在约 900px 桌面检查最复杂关系、最窄表格列、连续正文及顶部是否及时进入内容。静态、数值和实际渲染检查分别如实报告，不以有效绑定或可打开 HTML 证明语义与视觉质量。
