# 精简速览（brief）

仅 `brief` 读取本文件和 [Brief 模板](../assets/brief-report-template.html)，使用其内联 CSS 与 `brief-` 组件。完整理解来源后独立编辑，以醒目标题、编号和视觉关系表达主线，不逐章缩写成卡片长卷。公共事实边界适用，完整解释只覆盖本模式选中的核心内容。

## 篇幅与文字密度：交付硬约束

- **正文目标 1600–2200 字，上限 2400 字**。实际提取所有 `.brief-section` 可见文本，含标题、卡片、图表标签、条件与数字口径，去空白逐字符计数；题头、来源、页尾和折叠说明不计。短来源可低于目标，不凑字数。
- **段落、条目、表格单元格或节点说明通常 1–3 行，最多 4 行**，按约 900px 桌面、18px 正文与组件实际宽度测量；标题不计，条件计入，窄卡片不可直接塞通栏短段。
- **相邻独立正文最多两段、合计不超过 6 行；每章通栏叙述合计不超过 8 行。** 插小标题、横线、空白或改成列表不算打断连续文字，组件必须承担实际关系，文字仍计入总预算。
- 超预算先整项删除重复、辅助例子及细节，保留核心答案、决定性条件与代表依据；不能删单位、归属、限定或关键因果。无法在上限内讲清时说明原因，不默默交付 Standard 篇幅。
- 不用拆长段、堆小卡、巨卡、缩字号、机械换行、CSS 截断、固定高度遮挡或折叠正文规避限制。导语至多两句，不提前重复全文。

## 主线与阅读骨架

先分配篇幅，选核心问题、判断、决定性依据与条件，再组织少量大章节。每章解决一个主要问题，标题连起来能交代推进；主要主题保留关键判断即可，不以覆盖充分为由逐项复述。背景、例子与过程只在改变核心答案时保留，新闻背景可用开头短说明，不默认先讲行情或术语课。

同一事实和关系只展开一次；现有组件承担关系表达，短段补充必要上下文与解释。事件顺序重要时用关键转折时间轴，不罗列全部发言。不能以只剩结论或几段文字加色卡代替必要解释，也不为丰富版面轮换组件。

大章使用 `.brief-section > h2`，模板自动编号 `01、02、03`，不手写重复编号或取消大标题。章内最多一层具体小标题，同章子话题须分组，不只串写在章标题中。主标题、导语、完整来源与页尾遵守入口。

**正文不显示视频来源时间戳**，不生成 `.section-time`，回查依隐藏来源绑定与页尾说明；事件日期或时间可作为实际内容显示。不要把 Standard 时间规则带入本模式。

## 字号与视觉层级

保留模板白底、字体与明亮浅色；卡片颜色按语义一致，不调灰、调暗或暗示无依据的优劣。主标题 38px、章标题 30px、卡片标题 22px、正文及必要说明 18px，来源和页尾可稍小，条件、图注及图内标签不降小字。

条件与判断一起阅读，不写灰色小字旁注，也不以左短标签、右长段挤出窄栏。归属遵守共用规则，不重复“作者观点”“适用边界”“已有依据”等编辑栏名；直接写具体对象、期限、前提及不确定性。数字连同对象、单位和基准阅读，不逐个放大。

只复用现有组件，遵守入口的禁止自绘规则。主要用留白、对齐与编号分组，不铺满边框；组件已有细分支线、角线、折角可保留，一处用一种主装饰。同排 `.brief-pair` 卡片由模板等宽等高、顶部对齐，不以删字或固定高度凑齐。普通加粗遵守入口，不重复逐段强调。

## 组件按关系使用

模板末尾合成示例只说明结构，生成时替换为真实内容与绑定，删除示例注释。设计代号不展示；组件没有配额。

| 关系与组件 | 选择要点 |
|---|---|
| 条件分支 `.brief-branch-group`、`.brief-branch-origin`、`.brief-branches > .brief-branch` | 同一工具或决策的作用与边界，标签具体；可同时成立的分支不画成互斥选择 |
| 前后变化 `.brief-change`、`.brief-change-value`、`.brief-change-result` | 同对象、同口径的状态与结果，不暗示未证因果或虚假比例 |
| 留白判断 `.brief-open-card`、`.brief-boundary` | 一个判断与必要条件，短正文为主，具体条件需区分时才加短标签 |
| 参数算例 `.brief-case-card`、`.brief-case-params`、`.brief-case-result` | 参数、单位、条件、约数与结果一起读，与前后变化按重点二选一 |
| 观点或建议 `.brief-fold-card`、`.brief-fold-scope` | 条件融入正文，scope 仅有值得单列的具体条件时使用，不强填或追加总结 |
| 事件转折 `.brief-timeline > li > .brief-time-body` | `time` 事件日期、`h3` 转折、`p` 说明，节点至多三行；保留模板贯穿箭头，短节点可用 `data-layout="alternating"`，操作顺序仍用 `.brief-flow` |
| 一组关键数字 `.brief-facts > .brief-fact` | 同行等宽整体浅底容器，数值与口径分层；不另复述同数据或拼无共同意义的数字 |
| 后续观察 `.brief-watch > .brief-watch-item` | 按变量分组，具体标题加一两句判断与条件，单个说明区至多三行；确需两个方面对照才用 `.brief-watch-body`，不强填标签或结果 |
| 同章子话题 `.brief-topic`、`.brief-topic-title` | 标明归属范围，两个短方面可用 `.brief-topic-pair`，长解释单列 |
| 同主题并列维度 `.brief-dimension-group`、`.brief-dimension-tree`、`.brief-dimensions > .brief-dimension` | 共用标题统领，正文白底，分支无箭头，组内结论留在本组；模板按实际项数布局，不设置 `data-columns` 或为列数增删内容 |

`.brief-feature`、`.brief-pair > .brief-card` 可作简单强调与对照，短项 `.brief-list`，复杂关系用现有对照或表格，操作 `.brief-flow`，跨行比较 `.brief-table`；辅助 condition、note、caption 按需使用，必要文字同样保持完整与 18px。

时间轴只保留改变判断的转折，顺序真实，不能因先后补因果；只复用现有时间轴组件，不另绘曲线路径，不装入全部会议经过。观察、展望与建议按话题分组，不以长段、长列表或单一巨卡收尾。

并列维度沿用模板：两、三项的分支线连续并对齐标题中心；四项及以上自动两列续排并隐藏树线，不留下孤立连线或 3+1 尾项。长解释选择单列或其他结构，不用分栏突破行数预算。

### 表格列宽

短标签先留足宽度，再分配说明列与间距，不把两字标签挤成逐字换行。只有四列依次为“四字以内标签、两字以内标签、说明、说明”时，才按需用模板 `.brief-table-wrap > .brief-table[data-layout="labels"]` 的专用比例、说明列分隔与短标签不换行；其他结构依实际内容分配，不套通用固定比例。

该包装保留窄屏局部横向滚动、区域可读名称与键盘焦点。仍检查实际文本及行数，18px 正文不缩小，必要条件不删除。

## 交付前集中修订

以下模式检查全部纳入入口的唯一一轮集中检查，不另开专项检查：主标题与章标题是否清楚，主题是否重复，最密集处是否保留必要解释、依据和条件。

**在集中检查中实测总字数、单段行数、连续正文行数与每章通栏总行数，超限纳入同一次修订。** 静态检查无法测真实行数时说明，不声称通过。核对共用来源与文风规则，正文无来源时间戳。

在同一次约 900px 桌面检查中查看顶部、复杂区与结尾：标题编号醒目、说明可读，同排卡片等高，数字成组，时间轴箭头和节点相连，话题分组清楚，分支线对齐、无溢出与重叠。仅报告实际执行的检查，字数或截图高度不证明速览质量。
