# Core 候选方向与待办

## 待解决问题

- **正文内容质量的剩余问题**：真实固定输入仍出现重复归属、解释段落性质的尾句和局部判断强度漂移，跨块语义去重也未全面达标。单人自述应直接讲内容，自然保留必要的个人视角；多人和第三方引用保持真实主体，不能将个人体验泛化。现有检查器只定位转述候选，须结合原文判断。产业基线把原文相邻的“可能”和“很可能”均写成“很可能”，仍待处理。后置文风校订的一次端到端验证中，光学报告初稿仍遗漏弧矢像对应光线的仰角平面；该内容遗漏未由文风校订修复。此前两版通用文风候选在光学方向及产业供货关系上出现退步，未采纳；对照见 `.local/evals/written-style-closeout-20261102/SUMMARY.md` 和 `.local/evals/written-report-20261102/coverage.md`。

- **独立图示的发布与目标环境复核**：默认开启的后端参数、主 Agent 按需委派独立 Pi 会话与 HTML 自动嵌入已完成本地固定光学验证；按用户要求不增加前端选择。当前未推送、未部署，部署使用的 Pi 0.85／Docker 路径仍待实际复核。主流程通用检查长尾仍存在，不以本次结构与来源检查推断通用质量或效率，边界见 [架构](ARCHITECTURE.md#完成与检查)，样本与费用见 `.local/evals/benchmark-v1/isolated-diagram-optics-20261027/validation.md`。

- **组件复用与自检收敛的发布**：主报告已限制为复用现有 UI 组件，Skill 和 Pi 任务提示明确集中检查、至多一次修订；保留来源冲突处理和防御性措辞禁令。本地固定转写验证已观察到禁绘、请求数与长尾改善，当前未推送或部署。素材内矛盾的表达仍有残余问题，不能用效率指标代替保真结论；原始输出、同价费用对比与具体缺陷见忽略的 `.local/evals/benchmark-v1/components-only-deepseek-1017-20261027/comparison.md`。
- **Brief 表格视觉验证**：短标签与长说明方案已采纳，但候选桌面、窄屏与交互验证因先前浏览器限制未完成。继续时沿用原模板和实际内容，见 [设计偏好](report-design-preferences.md#brief短标签与长说明表格)。

- **运行与计时**：按原顺序串行各运行一次，复用现有入口和评测工具，不为评测另写生成流程。完成须有 `agent_settled` 及最终 `stopReason=stop`。保留首次尝试、失败与恢复记录，不静默重跑择优。分别统计主生成、检查/修订、独立图示、文风校订、渲染及完整交付耗时；嵌套或并发阶段不重复相加。与历史统一口径比较主 Agent 墙钟，另列当前完整流程耗时；缺失的历史分项标未知。汇总逐例变化、总计、中位数和范围，保留请求数及可得 token 用量，不从日志推断纯推理耗时。
- **语义与表达评审**：逐份对照冻结原文，记录核心内容覆盖、关键遗漏/新增、数字/公式/单位、条件和判断强度、因果与人物归属。分别评价直接讲述、重复和防御性措辞、段落衔接、术语解释、标题/目录辨识与逻辑关系；特别核对题头是否仍添加整理说明。每项改进或退步给出原文位置、前后具体片段与章节定位；历史评审只作线索，未全量核对的范围如实标明。
- **视觉与对比页**：在本轮忽略的评测目录交付 `comparison.html`，八例切换，左旧右新，清楚标注版本、模型和耗时；双栏独立滚动，提供可选同步滚动及单份新窗口打开。保持各报告 HTML/CSS 原样，以足够宽的报告视口显示，避免半屏压缩造成伪布局问题。附总览和逐例评语，评语不混入原报告。实际浏览八组对比、目录跳转、首屏/复杂区域/结尾，检查密度、层级、图表与公式、溢出/遮挡；保存并亲自查看代表性截图。
- **交付与边界**：八份新报告、八对可打开的 HTML 对比、配置清单、原始日志、耗时数据和有证据的综合结论均保存到 `.local/evals/benchmark-v1/current-vs-baseline-<执行日期>/`。分别列出改进、持平、退步和未验证项，不将单次八例结果外推成稳定性能结论。不修改历史基线、不在评测中润色新报告或调整 Skill，不部署；发现问题列后续修复建议。当前仅完成任务规划，尚未启动生成。

## 候选方向（未整体采纳、未排期）

- **合并收尾与按需截图（待用户审阅）**：两份复用转写、共用初稿和主会话历史的本机对照中，合并收尾均快于独立校订；个人体验稿仍有多处“自述者”式旁观转述，现有候选检查未识别该称呼。独立与合并方案在条件和个人体验的保留上各有缺口。实验默认只做全页程序检查，按需截取具体元素；不代表全篇视觉已获验证。结果与四份成稿见 `.local/evals/merged-finish-20261107/comparison.html`，尚未接入产品。

- **固定检查入口与首稿后收口**：固定光学日志的 22 次主请求中，完整首稿后仍有 14 次、约 98 秒；观察到截图未覆盖完整图示、模板长注释匹配失败，以及局部插入制造重复句后的二次修复。候选复用现有稳定占位符和检查工具，一次回传顶部／完整复杂区／结尾截图，集中整段修订、局部复核后由运行时收尾；不继续叠加同义提示或新增 Agent。仅分析和保留候选，未修改生成行为、未额外付费试跑，逐轮证据与耗时图见 `.local/evals/benchmark-v1/isolated-diagram-optics-20261027/tail-analysis-20261028/analysis.md`。

- **术语修正待目标环境验收**：任务开关、按需提示、Docker 输入/凭据/产物传递已接入；本机 Local Web 与真实 Docker 的 Sol 主 Agent / Luna 搜索合成字幕链路已通过。后续保留目标部署环境复核与真实输入语义效果评估，见[术语修正](term-correction.md)。
- **其余既有实验与分支暂缓**：Promptfoo 评测及 Knowledge Desktop 保留各自分支和本地材料，暂不合并或继续扩展。
- **完整 CLI 的 Python 安装包**：保留下载、转写、报告生成和渲染流水线及必需资源，排除开发文档、测试和评测材料；继续从同一 Core 源码构建。当前保留完整源码安装说明，是否提供独立安装包按实际用户需求决定。
- **独立报告内的证据回查**：将已有来源绑定用于可操作的原文、时间戳与视频定位，让下载后的 HTML 也便于核对关键结论；与 Knowledge Desktop 的阅读入口衔接，避免重复建设检索系统。
- **按阅读目标组织报告**：允许用户说明关注的问题、已有背景和用途，在保留 Standard/Brief 模式及来源边界的前提下调整内容重点。先验证同源报告是否更能帮助用户完成指定任务。
- **报告局部修订**：支持对指定段落或章节提出修订要求，复用已有转写，保留原报告与可查看的差异；先验证局部改动能否保留相邻内容和来源关系。
- **CLI 直接导入已有材料**：独立 Skill 已支持转写与字幕，候选是在标准 CLI 中补齐直接导入入口，再按需求考虑本地音视频，减少对单一视频平台下载入口的依赖。
- **可继续编辑的报告导出**：探索保留标题层级、表格与来源链接的 Markdown 导出，方便用户继续整理和使用；先确认真实使用需求，再考虑其他格式或外部应用集成。

没有新增已确认功能排期。候选保留不代表实施授权；产品级方向与跨仓发布由 Service 统筹，Core 不另维护一份完整产品路线图。
