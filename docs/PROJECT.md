# Video Report Core

## 目标与范围

将公开 Bilibili 视频转成可独立阅读、回查来源的 HTML 报告。Core 维护下载、ASR、规范转写、Pi 集成、唯一产品 Skill、渲染、CLI 与评测工具。账户、网站路由、额度、调度与运营部署由调用方负责。

## 当前能力

- 两条使用路径：独立复制 Skill 与模板，用自己的 Coding Agent 阅读完整转写；或通过 `video-report generate` 执行下载到报告的完整流水线。
- 流水线支持公开 Bilibili 视频及受限短链解析，最长 5 小时；CLI/Web 默认 `auto`，按作者字幕轨 → ai-zh → ASR 短路采用单路，Web OCR 关闭。主动选源可做多路对照／融合；Core 保留旧显式 ASR-only/fused 调用。
- 内置 ASR 为 Apple Silicon MLX Whisper 与百炼文件转写适配（支持代码列出的 Paraformer/Fun-ASR 模型）。满足时长与静音条件的云端长音频分两段并行识别，恢复原时间轴。
- Standard 用于不观看完整视频时理解主要论证、方法步骤与必要细节，并供查阅；Brief 用于几分钟内掌握结论、依据和重要限制，判断是否深入阅读，省略支线时仍须保留会改变结论的条件。两个模式读完整转写，各有规则与模板，可以复用同一来源转写。
- Pi 负责主 Agent 循环；默认提供按需图示工具，由独立 Pi 会话完成一个局部 SVG，Python 自动嵌入 HTML。主报告不自行绘图。支持 Local 宿主执行和显式 Docker 任务隔离；调用方可配置同会话有限模型恢复及最终模型。HTML 交付后尝试输出 PNG 长图。
- SQLite 保存来源正文、执行、报告与缓存事实，文件保留执行导出、大产物和原始日志；按参数、版本与字幕内容兼容条件复用下载、ASR 或完整转写。提供可选 `inspect_report` 和合成 smoke/A/B 工具。
- 用量工具聚合完成的 assistant 消息，分开返回美元与部分模型的人民币估算；ASR 按配置费率估算。
- 可选任务参数 `term_correction` 支持同一 Pi 按需辨名、来源取证与局部补丁，Local 和 Docker 共用实现；原始转写保留，开启即允许按需搜索，见[术语修正](term-correction.md)。
- 可选 `visual_enhancement` 默认关闭；开启后自动准备视频、抽帧并生成独立画面描述，与原字幕共同参与报告。描述使用已有 DeepSeek 凭据，报告保持原模型；转写缓存仍可复用。调用方负责入口与权限，见[架构](ARCHITECTURE.md#可选画面辅助理解)。

## 重要限制

- 下载器不支持任意平台；独立 Skill 可接受其他来源的文本。字幕/OCR 融合不是全面视频视觉理解。
- 执行期限默认 30 分钟，不含调用方排队；下载有独立的 120 秒执行预算。停止本地进程不保证取消已提交的云端 ASR。
- `RENDERED` 表示 HTML 交付，PNG 可能失败；Pi 正常结束、来源 ID 合法或页面可渲染均不证明语义忠实和阅读质量。
- Local 工作目录约束不是操作系统沙箱；Docker 的挂载、凭证与网络边界见 [架构](ARCHITECTURE.md)。同会话恢复保留有效上下文和文件，重新发起模型请求；不支持进程重启后自动续跑。
- 费用是代码费率与日志计算的估算，不是账单；独立 ASR 复用的估算缺口见 [PLAN](PLAN.md)。

## 评测口径

- **报告生成交付耗时**：从开始生成报告到完整报告可读，不包含此前的下载、转写和排队等待。
- **阅读偏好评价**：读者通过视觉浏览和粗略阅读，判断清晰度、阅读体验和用途匹配程度；不代表逐项核对原文。
- **参考总结**：同一视频的第三方总结，用于比较信息取舍与表达，可能有省略或错误；内容判断仍以源材料为依据。
- **成对参考样本**：同时具备源视频和第三方参考总结的样本，可用固定转写、Brief、Standard 与参考总结进行同源比较。
